## 5. 核心约定速查（改代码前必读）

- **认证**：`/v1/*` 错误=HTTP 401+OpenAI JSON；`/api/*`=HTTP 200+code 401；USER 访问 `/admin/*`=code 403。认证在 access 模块 filter 完成，控制器只收 X-User-Id。
- **SSE**：帧格式 `data:{json}`（无空格），前端 `slice(5).trim()`；终止哨兵 `data:[DONE]`；SseEmitter 必须裸返回（详见踩坑 2.1/2.2）。
- **结算口径**：`settled = success=1 OR interrupted=1`，全项目唯一。
- **双写分层**：reserve/settle 同步强一致；会话消息+日汇总走 BatchLogWriter（队列 1 万、批 500、500ms flush）；热统计在 Redis。
- **路由阈值**：SIMPLE_MAX_INPUT=500、COMPLEX_MIN_INPUT=2000、带 tools→complex、冷启动<20 样本走基线、score=w_q×normQ−w_c×normC。
- **Redis 前缀**：`token:blacklist:` `rate:limit:` `route:latency/quality/health/reqwin/errwin:` `route:payload-sample:`。
- **前端语义色**：用户 #2563eb / 模型 #0d9488 / 调用 #16a34a / 费用 #d97706 / tokens #0891b2 / 失败 #dc2626；健康 ≥75 绿 ≥50 琥珀。设计令牌在 global.css，**改值不改名**。
- **mapper**：接口加 `@Mapper` + 放对应模块包（@MapperScan 已覆盖），无需改启动类。
- **系统设置**：t_system_config（DB 覆盖 yml）→ common `SystemConfigHolder` 进程内持有；auth/access 读设置只读 Holder（缺行回退 yml），改库走 admin `SystemConfigService`（逐键校验+刷新 Holder+JWT 热更）。`/settings/**` 白名单免认证，只暴露 siteName/announcement 两键。
